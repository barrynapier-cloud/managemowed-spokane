Build Brief: Before/After Image Comparison Slider
A draggable horizontal slider that wipes between two images (a "Before" and "After" photo of the same property). Dark theme with a lime-green accent handle.

1. Dependencies (must be in <head> of host page)
<!-- Google Material Symbols (for icons in labels & handle) -->
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Symbols+Outlined" />

No JS libraries required. (Optional: GSAP + ScrollTrigger if you want the section to fade in on scroll — not required for the slider itself to function.)

2. Assets
Two images, ideally same camera angle, same aspect ratio, recommended 16:9 (e.g. 1920×1080):

assets/before-property.png — the "before" / neglected state
assets/after-property.png — the "after" / improved state

5. JavaScript
Vanilla JS — no dependencies. Place at the end of <body> or inside a DOMContentLoaded handler.

<script>
(function () {
  var slider = document.getElementById('baSlider');
  var handle = document.getElementById('baHandle');
  if (!slider || !handle) return;
  var beforeEl = slider.querySelector('.ba-before');
  var isDragging = false;
  function getPosition(e) {
    var rect = slider.getBoundingClientRect();
    var x = e.touches ? e.touches[0].clientX - rect.left : e.clientX - rect.left;
    return Math.max(0, Math.min(x / rect.width, 1));
  }
  function updateSlider(pos) {
    var pct = pos * 100;
    beforeEl.style.clipPath = 'inset(0 ' + (100 - pct) + '% 0 0)';
    handle.style.left = pct + '%';
  }
  slider.addEventListener('mousedown', function (e) { e.preventDefault(); isDragging = true; updateSlider(getPosition(e)); });
  slider.addEventListener('touchstart', function (e) { isDragging = true; updateSlider(getPosition(e)); }, { passive: true });
  window.addEventListener('mousemove', function (e) { if (!isDragging) return; e.preventDefault(); updateSlider(getPosition(e)); });
  window.addEventListener('touchmove', function (e) { if (!isDragging) return; updateSlider(getPosition(e)); }, { passive: true });
  window.addEventListener('mouseup',  function () { isDragging = false; });
  window.addEventListener('touchend', function () { isDragging = false; });
})();
</script>

6. How it works (so the agent understands intent)
Two images stacked absolutely inside .ba-slider, both filling the box at 16:9.
The "After" image is the base layer (always fully visible).
The "Before" image is on top with clip-path: inset(0 50% 0 0) — initially clipped to show only the left half.
The handle is a vertical lime line + circle pinned at left: 50%.
On drag, JS updates the before image's right inset (0–100%) and moves the handle's left position to match.
The handle has pointer-events: none so the slider container always receives the mouse/touch events — drag works smoothly across the entire width.
7. Notes for matching brand exactly
Background of section: #111820 (dark slate)
Accent / handle / "After" label: #ccff00 (lime)
"Before" label: rgba(255,68,68,0.85) (red)
Container max-width: 960px for the slider, 1200px for the section
Recommended image ratio: 16:9 — if you change it, update aspect-ratio: 16 / 9; on .ba-slider to match
That's everything. Hand the above to the other agent and they should be able to drop it in unchanged.
