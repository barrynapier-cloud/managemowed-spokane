Build Brief: Animated "Count-Up" Stats Section
A row of 4 large lime-green numbers that animate from 0 up to their target value when the section scrolls into view. Each number sits above an uppercase label, separated by thin vertical divider lines. Fully responsive (4 cols → 2 cols → 1 col).

1. Dependencies
None. Pure vanilla JS, no libraries required.

2. HTML
<section class="stats-counter" id="stats-counter">
  <div class="container">
    <div class="stats-grid">
      <div class="stat-item">
        <div class="stat-number" data-target="24">0</div>
        <div class="stat-label">Locations Nationwide</div>
      </div>
      <div class="stat-item">
        <div class="stat-number" data-target="980" data-suffix="K+">0</div>
        <div class="stat-label">Sq Ft Managed Monthly</div>
      </div>
      <div class="stat-item">
        <div class="stat-number" data-target="92" data-suffix="%">0</div>
        <div class="stat-label">Client Retention Rate</div>
      </div>
      <div class="stat-item">

To customize: change the data-target (the final number), data-suffix (any string appended after — e.g., %, K+, +, M), and the .stat-label text. Add or remove .stat-item blocks; the grid auto-handles column count.

4. JavaScript
Place at the end of <body> or inside a DOMContentLoaded handler.

<script>
(function () {
  var counters = document.querySelectorAll('.stat-number');
  if (!counters.length) return;
  var animated = false;
  function animateCounters() {
    if (animated) return;
    var section = document.querySelector('.stats-counter');
    if (!section) return;
    var rect = section.getBoundingClientRect();
    if (rect.top < window.innerHeight * 0.85) {
      animated = true;
      counters.forEach(function (el) {
        var target = parseInt(el.getAttribute('data-target'));
        var suffix = el.getAttribute('data-suffix') || '';
        var duration = 2000;       // total animation length in ms
        var startTime = null;
        function step(timestamp) {
          if (!startTime) startTime = timestamp;
          var progress = Math.min((timestamp - startTime) / duration, 1);
          var eased = 1 - Math.pow(1 - progress, 3);   // ease-out cubic
          var current = Math.floor(eased * target);
          el.textContent = current + suffix;
          if (progress < 1) {
            requestAnimationFrame(step);
          } else {
            el.textContent = target + suffix;
          }
        }
        requestAnimationFrame(step);
      });
    }
  }
  window.addEventListener('scroll', animateCounters, { passive: true });
  animateCounters();   // also fire on load in case section is already in view
})();
</script>

5. How it works (so the agent understands intent)
A scroll listener watches the section's position. When its top crosses 85% of the viewport height (i.e., user has scrolled it into clear view), the counters fire.
Each counter uses requestAnimationFrame with an ease-out cubic curve, so numbers race up fast and decelerate near the target — feels lively, not linear.
animated = true ensures it only runs once per page load.
data-suffix lets each stat have its own trailing string (K+, %, etc.) without baking it into the number.
That's the whole package. Hand it to the other agent and the section will look and behave identically.
