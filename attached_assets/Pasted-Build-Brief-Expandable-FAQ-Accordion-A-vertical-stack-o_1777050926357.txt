Build Brief: Expandable FAQ Accordion
A vertical stack of clickable questions. Click one to slide its answer open, click again (or click another) to collapse. Lime accent on the chevron icon (rotates 180° when open) and a subtle lime border around the active card.

1. Dependencies
<!-- Google Material Symbols (for the expand_more chevron) -->
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Symbols+Outlined" />

No JS libraries required.

4. JavaScript
Vanilla — place at the end of <body> or inside a DOMContentLoaded handler.

<script>
(function () {
  var faqItems = document.querySelectorAll('.faq-item');
  faqItems.forEach(function (item) {
    var btn = item.querySelector('.faq-question');
    btn.addEventListener('click', function () {
      var isActive = item.classList.contains('active');
      // Close all other items (accordion behavior — only one open at a time)
      faqItems.forEach(function (other) {
        other.classList.remove('active');
        var otherBtn = other.querySelector('.faq-question');
        otherBtn.setAttribute('aria-expanded', 'false');
      });
      // Toggle the clicked one
      if (!isActive) {
        item.classList.add('active');
        btn.setAttribute('aria-expanded', 'true');
      }
    });
  });
})();
</script>

5. How it works
Each card starts collapsed (max-height: 0, aria-expanded="false").
Click the question → JS adds .active to that .faq-item, which triggers two CSS transitions: the max-height opens to 600px (smooth slide-down), and the chevron rotates 180°.
Clicking another question first removes .active from the open one, so only one answer is visible at a time (classic accordion behavior). Click the same question again to close it.
aria-expanded is kept in sync for screen readers.
6. Customizing
More/fewer questions — just add or remove .faq-item blocks. JS handles them automatically.
Allow multiple open at once — delete the inner faqItems.forEach(...) loop in the JS.
Different brand color — change --accent (chevron color, hover color, active border).
Wider container — change max-width: 800px on .faq-grid.
That's the complete drop-in package.
